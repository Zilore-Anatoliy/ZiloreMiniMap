Quick Answers

Frequently Asked Questions

Fast fixes for common questions. Read the full list in our GitHub FAQ.

Can ZiloreMiniMap trigger an Easy Anti-Cheat (EAC) ban?

No. ZiloreMiniMap operates purely as an external window overlay without reading game memory, modifying game files, or injecting DLLs. Coordinates come strictly from SCUM's built-in Copy Location action.

Why is the minimap not visible over SCUM?

Open SCUM Settings → Video and switch Display Mode from Fullscreen to Windowed Fullscreen (Borderless). Exclusive fullscreen prevents Windows from displaying external overlays.

Windows SmartScreen warned me about Setup — is it safe?

Yes, provided you downloaded it from our official GitHub and verified its signature/SHA-256 against SHA256SUMS.txt. SmartScreen flags newly released software signed by independent developers until download reputation grows. Click "More info" → "Run anyway".

How do I get the smoothest performance on a 2K / 4K 144Hz monitor?

Open Settings → Appearance, enable Hardware-accelerated M map (GPU), and restart the app to switch the tactical map to direct GPU rendering with crisp ClearType text at 125–200% DPI scaling.

Will updates keep my waypoints, routes, and custom zones?

Yes. All user data is stored safely in your Windows user profile and preserved across updates. You can also export/restore a complete ZIP backup anytime under About → Support.

What is free vs. what uses an optional POI / Zilore AI key?

The entire core suite (minimap HUD, tactical map, road routing, squad radar, server clock, climate, aviation, zones, voice guidance, profile backup, and all 4 themes) is 100% free. Extended POI database filters and Zilore AI unlock via offline access keys (1–24 hours or 30/90/180/365 days) for voluntary project supporters.
